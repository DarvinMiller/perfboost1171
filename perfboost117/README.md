# PerfBoost (Fabric 1.17.1)

Сборка: `./gradlew build` (JDK 17 или 21; мод собирается под Java 16) → `build/libs/perfboost-1.0.0.jar` в `mods/`.
Нужны Fabric Loader и Fabric API (0.46.1+1.17 для 1.17.1). Настройки: кнопка «PerfBoost» в меню ESC или F9;
конфиг `config/perfboost.json`.

Возможности: «Рекомендуемое ВКЛ/ВЫКЛ» (авто-подбор по железу и FPS), отсечение и заморозка вне обзора
(частицы, сущности, слои), дальности брони/оружия/плащей/скина/glint/частиц/предметов, сон падающих блоков,
лимит тиков предметов, скрытие сущностей в меню ESC.

Новое: частицы вне обзора не создаются, тени, сундуки/таблички, рамки/стойки, LOD мобов, окно статистики.

Миксины мягкие (`defaultRequire: 0`): если что-то не применилось, игра не падает, а функция не включается —
смотрите `latest.log` (строки Mixin/perfboost).
